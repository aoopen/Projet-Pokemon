# 🎮 Analyse et visualisation de données Pokémon

## 📌 Présentation du projet

Ce projet consiste à explorer, nettoyer et analyser un jeu de données consacré à l'univers Pokémon.

L'objectif est de transformer un fichier CSV brut en une base de données structurée et exploitable, puis de réaliser des visualisations afin de mieux comprendre les caractéristiques des Pokémon.

Ce projet permet de mettre en pratique les compétences essentielles d'un Data Analyst : préparation des données, traitement des valeurs manquantes, analyse exploratoire et visualisation.

## 🎯 Objectifs

- Importer et explorer un jeu de données CSV.
- Nettoyer les données et corriger les anomalies.
- Identifier et supprimer les doublons.
- Corriger les types de données et les valeurs manquantes.
- Structurer les caractéristiques des Pokémon.
- Réaliser des visualisations pour faire ressortir des tendances.

## 🛠️ Technologies utilisées

- **Python** : langage de programmation.
- **Pandas** : manipulation et nettoyage des données.
- **NumPy** : calcul et traitement numérique.
- **Jupyter Notebook** : exploration et analyse des données.
- **Matplotlib / Seaborn** : visualisation des données, selon les notebooks.

## 🔎 Étapes du projet

### 1. Exploration des données
- Importation du fichier CSV.
- Analyse de la structure du dataset.
- Identification des colonnes et des anomalies.

### 2. Nettoyage des données
- Correction des formats numériques.
- Harmonisation des noms.
- Suppression des doublons.
- Gestion des valeurs manquantes.
- Correction des statistiques individuelles (attaque, défense, vitesse, etc.).
- Traitement des colonnes contenant plusieurs valeurs.

### 3. Analyse et visualisation
- Exploration des caractéristiques des Pokémon.
- Analyse des statistiques.
- Comparaison des différentes générations et catégories.
- Création de visualisations pour faciliter l'interprétation des données.

## 🚀 Installation et utilisation

Cloner le dépôt :

```bash
git clone https://github.com/aoopen/Projet-Pokemon.git
cd Projet-Pokemon
```

Installer les principales dépendances :

```bash
pip install pandas numpy jupyter matplotlib seaborn
```

Lancer Jupyter Notebook :

```bash
jupyter notebook
```

Ouvrir les notebooks :
1. `nettoyage_csv_pokemon.ipynb`
2. `visualisation.ipynb`
